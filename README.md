# 📊 Full-Cycle Bookkeeping Portfolio — Bluepeak Creative Studio LLC

**A complete Q1 2026 bookkeeping cycle for a mock US small business, built with QuickBooks Online, Python, Excel, and Power BI following US GAAP.**

---

## 🏢 The Mock Business

| Field | Detail |
| :--- | :--- |
| **Legal Name** | Bluepeak Creative Studio LLC |
| **Location** | Austin, Texas |
| **Industry** | Graphic Design & Branding Services |
| **Structure** | Single-Member LLC (2 members, 50/50) |
| **Employees** | 1 part-time W-2 employee |
| **Basis** | Accrual |
| **Period** | January 1 – March 31, 2026 (Q1) |

---

## 🎯 What This Project Demonstrates

- ✅ Full-cycle bookkeeping — from chart of accounts to financial statements
- ✅ QuickBooks Online proficiency (bank feed, reconciliation, adjusting entries)
- ✅ US GAAP knowledge (accrual basis, ASC 606, matching principle)
- ✅ Python automation (transaction generation, bank statement creation, CSV conversion)
- ✅ Excel and Power BI dashboarding

## 🔍 Workflow Phases

1. **Business Design** — 31-account chart of accounts
2. **Python Generation** — 90 realistic transactions
3. **Bank Reconciliation** — 3 discrepancies resolved to $0 variance
4. **Month-End Close** — 3 adjusting journal entries
5. **Financial Statements** — Income Statement, Balance Sheet, Cash Flow
6. **Power BI Dashboard** — 4-chart interactive dashboard
7. **GAAP Memo** — 1-page documentation of accounting policies
